## 整体流程概览

```
用户访问页面
    │
    ▼
[normal-form.tsx] 检测已有 session + isLoggedIn
    │ 已登录 → 直接跳转 /apps
    │ 未登录 ↓
    ▼
[sso-auth.tsx] 点击 SSO 登录按钮
    │
    ▼
[sso.ts] getUserOAuth2SSOUrl() 构造 Keycloak 授权 URL
    │
    ▼
浏览器跳转到 Keycloak 授权页面完成认证
    │
    ▼
Keycloak 回调 /api/auth/sso?code=xxx
    │
    ▼
[app/api/auth/sso/route.ts] 用 code 换取 session_id，写入 httpOnly cookie
    │
    ▼
跳转 /apps，登录完成
    │
    ▼
后续所有 API 请求：
[fetch.ts] beforeRequestAuthorization → fetchKeycloakAccessToken()
    │  命中缓存（20s 内）→ 直接使用
    │  缓存过期 → 请求 /sso/oauth2/access-token（携带 session cookie）
    ▼
请求头注入 Authorization: Bearer <access_token>
    │
    ▼
后端 API 验证 token
    │ 401（Keycloak token 过期，无法刷新）↓
    ▼
[fetch.ts] fetchKeycloakAccessToken 401 handler
    │  1. 保存当前 URL 到 localStorage['oauth_authorize_pending']
    │  2. 清除 has_sso_session cookie（防止 SSO 验证死循环）
    │  3. 跳转 /signin
    ▼
用户重新 SSO 登录 → Keycloak → /api/auth/sso → /apps
    │
    ▼
[app-initializer.tsx] AppInitializer.useEffect
    │  resolvePostLoginRedirect → 读 oauth_authorize_pending
    └─ location.replace(savedUrl) → 回到原页面 ✅
```

## 1. 登录入口检测 — `normal-form.tsx`

**文件路径：** `web/app/signin/normal-form.tsx`

登录页初始化时，`init()` 函数检测是否已登录：

```typescript
const hasSession = document.cookie.includes('session=')

if (isLoggedIn && hasSession) {
  setIsRedirecting(true)
  const redirectUrl = resolvePostLoginRedirect(searchParams)
  router.replace(redirectUrl || '/apps')
```

<Note>
  `isLoggedIn` 来自 `useIsLogin()` hook，调用后端 `/console/api/setup` 检查。
  `hasSession` 检测 cookie 是否包含 `session=` 字符串（`has_sso_session=1` 也包含该子串），两者都满足才自动跳转。
</Note>

## 3. 构造 Keycloak 授权 URL — `service/sso.ts`

**文件路径：** `web/service/sso.ts`

```typescript
export const getUserOAuth2SSOUrl = async (): Promise<string> => {
  const redirectUriOrigin = process.env.NEXT_PUBLIC_WEB_PREFIX as string
  const params = {
    client_id: process.env.KEYCLOAK_CLIENT_ID,
    response_type: 'code',
    redirect_uri: `${redirectUriOrigin}/api/auth/sso`,
    scope: 'openid',
  }
  const url = new URL(
    `${process.env.KEYCLOAK_BASE_URL}/auth/realms/${process.env.KEYCLOAK_REALM}/protocol/openid-connect/auth`
  )
  Object.entries(params).forEach(([key, value]) => {
    url.searchParams.append(key, value as string)
  })
  return url.toString()
}
```

## 4. OAuth2 回调处理 — `app/api/auth/sso/route.ts`

Keycloak 认证成功后，携带 `code` 参数回调 `/api/auth/sso`：

```typescript
export async function GET(request: NextApiRequest) {
  const authorizationCode = new URL(request.url!).searchParams.get('code')

  const serverResponse = await fetch(
    `${getLoginApiPrefix()}/console/api/sso/oauth2/callback?${params.toString()}`
  )
  const sessionId = (await serverResponse.json()).data?.session_id

  response.cookies.set('session_id', sessionId, {
    httpOnly: true,
    sameSite: 'lax',
    secure: isProd,
    maxAge: 24 * 60 * 60,
    path: '/',
  })

  response.cookies.set('has_sso_session', '1', {
    httpOnly: false,
    sameSite: 'lax',
  })

  return NextResponse.redirect(new URL(`${redirectUriOrigin}/apps`))
}
```

<Warning>
  **不设置 `domain`**：避免 INT/PROD 多环境的 cookie 互相覆盖。
</Warning>

## 5. Access Token 获取与缓存 — `service/fetch.ts`

每次发 API 请求前，自动获取短时效的 access token 并注入 Authorization header。

### 5.1 缓存机制

```typescript
function createKeycloakAccessTokenFetcher() {
  const cacheDuration = 20000
  let cachedAccessToken: string | undefined
  let tokenTimestamp: number | undefined
  let isFetching = false

  return async function getAccessToken() {
    const now = Date.now()

    if (cachedAccessToken && tokenTimestamp && now - tokenTimestamp < cacheDuration)
      return cachedAccessToken

    if (isFetching) {
      while (isFetching) await new Promise(r => setTimeout(r, 100))
      return cachedAccessToken!
    }

    isFetching = true
    try {
      const response = await fetch(`${API_PREFIX}/sso/oauth2/access-token`, {
        credentials: 'include',
      })
      const data = await response.json()
      cachedAccessToken = data.access_token
      tokenTimestamp = now

      if (response.status === 401) {
        cachedAccessToken = undefined
        tokenTimestamp = undefined
        const currentUrl = location.pathname + location.search
        localStorage.setItem('oauth_authorize_pending', JSON.stringify({ value: currentUrl }))
        document.cookie = 'has_sso_session=; Max-Age=0; path=/'
        location.href = `${location.origin}${basePath}/signin`
      }
    } finally {
      isFetching = false
    }
    return cachedAccessToken
  }
}
```

<Tip>
  **为什么要清除 `has_sso_session`？**
  若不清除，`normal-form.tsx` 会因 `isLoggedIn && hasSession=true` 自动跳回 `/apps`，而 Keycloak token 仍然 401，形成无限死循环。
</Tip>

### 5.2 请求自动注入

```typescript
const beforeRequestAuthorization: BeforeRequestHook = async (request) => {
  const token = await fetchKeycloakAccessToken()
  const requestUrl = new URL(request.url)
  const apiUrl = new URL(process.env.NEXT_PUBLIC_API_PREFIX as string)

  if (requestUrl.hostname === apiUrl.hostname)
    request.headers.set('Authorization', `Bearer ${token}`)
}
```

## 6. Token 刷新与重新登录 — `service/refresh-token.ts`

### 跨标签页防重复刷新

```typescript
async function getNewAccessToken(timeout: number) {
  const isRefreshingSign = localStorage.getItem('is_other_tab_refreshing')
  if (isRefreshingSign === '1' || isRefreshing) {
    await waitUntilTokenRefreshed()
    return
  }

  isRefreshing = true
  localStorage.setItem('is_other_tab_refreshing', '1')
  localStorage.setItem('last_refresh_time', Date.now().toString())

  const [error, ret] = await fetchWithRetry(
    fetch(`${API_PREFIX}/refresh-token`, { method: 'POST', credentials: 'include' })
  )

  if (error || ret.status === 401) return Promise.reject(error || ret)
}

export async function refreshAccessTokenOrRelogin(timeout: number) {
  return Promise.race([
    new Promise<void>((_, reject) => setTimeout(() => {
      releaseRefreshLock()
      reject(new Error('request timeout'))
    }, timeout)),
    getNewAccessToken(timeout),
  ])
}
```

### 8.2 恢复原页面（`AppInitializer`）

```typescript
useEffect(() => {
  (async () => {
    const isFinished = await isSetupFinished()
    if (!isFinished) { router.replace('/install'); return }

    const redirectUrl = resolvePostLoginRedirect(searchParams)
    if (redirectUrl) {
      location.replace(redirectUrl)
      return
    }
    setInit(true)
  })()
}, [pathname, searchParams])
```

### 8.3 完整链路

```
用户在 /apps/abc123/workflow
    ↓  Keycloak token 过期
fetchKeycloakAccessToken → 401
    ├─ localStorage['oauth_authorize_pending'] = { value: '/apps/abc123/workflow' }
    ├─ has_sso_session cookie 清除
    └─ location.href = '/signin'
    ↓
normal-form.tsx: isLoggedIn && hasSession=false → 展示 SSO 按钮
    ↓
用户 SSO 登录 → Keycloak → /api/auth/sso → cookies → redirect /apps
    ↓
AppInitializer → resolvePostLoginRedirect
    → getItemWithExpiry('oauth_authorize_pending')
    → location.replace('/apps/abc123/workflow') ✅
```
