## Git Tips

**Undo last commit but keep changes:**

```bash
git reset --soft HEAD~1
```

**Stash only staged changes:**

```bash
git stash --staged
```

## Node.js Snippets

**Check which port is listening:**

```bash
# Windows
netstat -ano | findstr :3000

# Mac / Linux
lsof -i :3000
```

**Quick HTTP server:**

```bash
npx serve .
```
