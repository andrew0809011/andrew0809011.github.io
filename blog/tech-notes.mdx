## Git

**撤销最后一次提交（保留改动）：**

```bash
git reset --soft HEAD~1
```

**仅暂存已暂存的改动：**

```bash
git stash --staged
```

**查看某个文件的修改历史：**

```bash
git log --follow -p -- path/to/file
```

## Node.js

**查看哪个进程占用了端口：**

```bash
# Windows
netstat -ano | findstr :3000

# Mac / Linux
lsof -i :3000
```

**快速启动本地 HTTP 服务：**

```bash
npx serve .
```

**检查包的真实安装路径：**

```bash
npm root -g
```

## Python

**创建并激活虚拟环境：**

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# Mac / Linux
source .venv/bin/activate
```

**一次性安装所有依赖：**

```bash
pip install -r requirements.txt
```

<Tip>
  使用 `pip freeze > requirements.txt` 导出当前环境的依赖清单。
</Tip>
